# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main`.

| Version | Supported |
| --- | --- |
| `main` | ✅ |
| Older commits, forks, or local modifications | ❌ |

## Reporting a vulnerability

Please do not open public issues for security-sensitive reports.

1. Use the repository security page or GitHub private vulnerability reporting for this repository if it is available: [github.com/mauragas/gnome-shell-extensions/security](https://github.com/mauragas/gnome-shell-extensions/security).
2. If private reporting is not available, contact the maintainer privately through the GitHub profile before disclosing publicly: [github.com/mauragas](https://github.com/mauragas).
3. Include the affected extension UUID, impact, reproduction steps, and any proof-of-concept details needed to validate the report.

## Disclosure

Reports will be reviewed and validated as quickly as possible. When confirmed, fixes should land on `main` before broader public disclosure.
